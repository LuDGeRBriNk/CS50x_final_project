# YACC - Yet Another Complex Calculator
#### Video Demo: [https://youtu.be/sq9nDxe0XCY](https://youtu.be/sq9nDxe0XCY)

Welcome to YACC, a sleek, live-evaluating desktop calculator built in Python using `tkinter`.
Designed to resemble a classic table calculator, it is secure, and visually intuitive. We have designed it to handle arithmetic with real or complex numbers seamlessly, returning outputs in a human friendly format similar to how one sees in mathematics text books!


# The Libraries:

`YACC` does not require any external libraries. The only required ones (all native to python) are:
* **Tkinter:** To render the app itself on the screen, with its buttons and overall layout. Extensive research has been made to use this framework. Much of the code here present have developed from snippets taken from the examples present in the official documentation page: https://docs.python.org/3/library/tk.html. Tkinter also allowed us to write the whole logic as functions of a class "Calculator".
* **Math:** To perform the actual math operations we rely on the Math library. Effectively `YACC` is just a GUI frontend for the Math library with some wrapping functionalities.
* **Cmath:** Same as above, but with complex numbers.
* **Re (regex):** To capture patterns of multiplication that do not include the `*` symbol such as `2π` instead of `2*π`, allowing for a more natural writing of expressions by using Implicit Multiplication. Some AI support was required for implementing this functionality as per the disclaimer below:

**AI Usage Disclaimer:**
AI support was required to obtain the regex strings to compare against user input for the implicit multiplication functionality. The "raw" strings (r strings) such as `r'(\d+\.?\d*)\s*(?=[ieπφ])'` have been explicitly generated by AI (present in lines 228 through 236).

No other part of the code has had its syntax written explicitly by AI.


# List of Features:

* **Live Evaluation:** The main feature. No need to constantly hit equals! `YACC` evaluates the user expression as they type, displaying live results in green, or a subtle `...` if it is waiting for more input. The equal sign still serves the functionality of inserting the current output to the input field for chained calculations.
* **Addressed Security:** The live evaluation introduces a security issue, and therefre is strictly sandboxed. We "blind" `eval()` to protect against code injection while allowing safe math operations. While not mitigating against every possible code injection attack from a creative user, it is secure enough to run locally in a person's own machine. More on mitigating the usage of `eval()` against code injection at https://realpython.com/python-eval-function/.
* **Complex Number Support:** Fully supports imaginary numbers (`i`) operations. One notable limitation is calculating the n-th root of a number, which returns a single result while mathematics guarantees there are n solutions.
* **Seamless sqrt():** Square root function has been redesigned to call the proper library in case a negative value is input, allowing for seamless operations between real and complex numbers.
* **Toggable Output Mode:** The user can select whether they want the output shown in cartesian (rectangular) form `a + bi` or the polar form `r*e^(i*ϴ)`. We have left a π factor multiplying the exponent for human readability. As for the input, it simply works either way.
* **More functions with the `SHIFT` Key:** Clicking on `YACC`'s SHIFT key, or holding the physical heyboard SHIFT key visually swaps standard buttons to their inverse counterparts right on the screen (e.g., `sin` becomes `asin`, `^` becomes `sqrt`, `exp` becomes `log` etc). Visual cues of this "alternative mode" are shown by a change of colors and function names.
* **Constants & Auto-Replacement:** Dedicated buttons for `π`, `e` and `i` are a click away. Also, typing "pi" or "phi" (the golden ration) via keyboard instantly "auto-corrects" to the proper Greek symbols.
* **Implicit Multiplication:** Support to human friendly typing, not requiring `*` at every multiplication. Typing `2π`, `eφ` or even `ecos(pi)` will be automatically understood as a multiplication. This is achieved by piping the input through complex `regex` conditions and then properly converting user input into valid python's math (or cmath) expressions. These last two features together mean that, for example, a user types `epipi`, gets `eππ` as visual output while what is computed is effectively `e*pi*pi` per the math library; all of these adding to a powerful and clean UX.
* **Support to Classical Functions:** Despite not being in `YACC`'s layout, the user can refer to functions by their classical name, such as `ABS()` for the modulus (or absolute value) of a number, for example.
* **Smart Output:** `YACC` is not a CAS (Computer Algebra System), but after a calculation is made, the output goes through a thorough process that ensures a pleasurable reading. Not only we avoid typical floating point imprecisions, but also we ensure the end format matches the classical notation.
* **Seamless Input Switching:** The input field actively managed the cursor position (tkinter's `icursor`). So the user can fluidly switch between clicking and typing without ever losing the cursor of place.
* **Color Coded Layout:** Inspired by office table calculators and with an intuitive color scheme to make usage a pleasure.

# Running YACC:

Because YACC is built entirely with Python's standard libraries, there is no need to set up virtual environments or install external packages. Except by a minority of systems, as long as you have Python 3 installed, you are ready to go! At most install the `tk` package if running from a sleak system.
Save the .py file to your machine and run with `python yacc.py`.
